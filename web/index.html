Classify text

The router decides which model answers. In shadow every request is served by v1 while v2 also runs and its answer is recorded but never returned. From canary 5 onward a share of requests is genuinely served by v2. Identical text is cached, so a repeat of the same input returns in well under a millisecond.

What just happened

Every field the API returns, unedited. model_used is which model actually answered; cache_hit tells you whether inference ran at all.

No prediction yet—

A canary rollout gives a new model a small share of live traffic, watches it against fixed thresholds, and either advances it or pulls it back. Promotion here is manual. Any breached threshold triggers an automatic rollback to shadow and flushes the cache, so no answer produced by the suspect model can be served again from memory.

Traffic split

—

Promotion is one step at a time: shadow → canary 5 → 25 → 50 → full. Rolling back skips straight out of the progression and flushes the cache, because an answer produced by a model you have just stopped trusting should not be served again from memory.

—

Circuit breaker

Trips after repeated v2 failures and sends everything to v1 until it is reset. It is the floor under the rollout: even if a threshold is missed, a failing model stops being asked.

Both models score every request even when only one answer is returned, so their outputs can be compared continuously. Disagreement is the most useful early signal there is: it rises before accuracy visibly drops, and it needs no labels to compute. The trace below plots the confidence gap on each of the most recent disagreements — a large gap means one model was confidently wrong rather than both being unsure.

Most recent cases

Drift is the input distribution moving away from what the model was validated on. A reference window is frozen at startup, and each later batch is compared against it on two features: input length and prediction confidence. The score is 0 when the distributions are identical and 1 when they share nothing. Evidently computes it where it is installed, otherwise a Jensen-Shannon fallback does — the method used is reported below rather than assumed. Nothing here looks at correctness; it only asks whether the traffic still resembles what this model was measured on.

Last check

Identical input text returns a stored answer instead of running inference. This deployment runs a single instance, and one instance means one cache — so an in-process dictionary with a TTL is not an approximation of Redis here, it is the same thing without the network hop or the account. The backend is reported below rather than hidden, because a fallback that quietly inherits the name of the thing it replaced would hide a real outage.
